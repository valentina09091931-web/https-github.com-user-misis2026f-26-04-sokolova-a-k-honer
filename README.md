Здесь представлены мои домашние задания по ВВС.

Домашнее задание 1 (калькуляторы):
В простом калькуляторе реализован обычный калькулятор реализованный одной функцией.
Калькулятор ИМТ реализован через класс, выводит ИМТ, вашу категорию, нормальный вес.

Домашнее задание 2 (красивая строка):
Через классы выполнена программа, которая может редактировать введенную строку по выбранному параметру.

Домашнее задание 3 (лабиринт):
Через классы реализована консольная игра-лабиринт с генерацией поля 5×5. Игрок собирает ключ, оружие, сокровища, спасает принцессу и избегает ловушек и монстров, чтобы добраться до выхода.

Домашнее задание 4 (Титаник):
С помощью библиотек Pandas и NumPy выполнен первичный анализ датасета пассажиров: обработаны пропущенные значения (заполнение медианой и удаление столбца Cabin), посчитана статистика по возрасту, полу, классу каюты и выживаемости, а также сформированы итоговые CSV-отчёты.

Домашнее задание 5 (интерфейсы):
Реализованы две десктопные версии игры «Быки и коровы» на библиотеках Tkinter и PyQt6: с выбором длины числа (3–5 цифр), проверкой корректности ввода, подсчётом попыток и отображением истории ходов и результатов.

Домашнее задание 6 (база данных):
С помощью модуля sqlite3 к игре подключена база данных для хранения истории партий. Реализованы запись результатов каждого игрока, подсчёт рекордов для разной длины числа и вывод общей статистики в отдельном окне.
